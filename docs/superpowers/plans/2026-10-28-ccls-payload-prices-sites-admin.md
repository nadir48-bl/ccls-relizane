# CCLS Relizane — Payload Core, Live Prices, Sites & Staff Dashboard — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put Payload CMS inside the existing Next.js app so staff can update prices and sites from an Arabic dashboard, and the public `/tarifs`, home page, and network section read that data without a rebuild.

**Architecture:** Payload 3 is mounted at `/admin` in the same Next.js 16 app. The public site moves into `app/(frontend)` with its own root layout; Payload's generated files live in `app/(payload)`. Server Components read through the Payload Local API with `overrideAccess: false`; `afterChange` hooks call `revalidatePath`. SQLite is used for local development and tests; PostgreSQL is the production adapter, selected by `DATABASE_URI`.

**Tech Stack:** Next.js 16.4.3, React 19.3, Payload 3.92.1, TypeScript 6.0.3, Tailwind CSS 4, Leaflet + OpenStreetMap, Vitest, Playwright, axe-core.

**Spec:** `docs/superpowers/specs/2026-10-28-ccls-relizane-prices-network-account-design.md`

## Global Constraints

- Node **24.22.1+**; the current machine has 22.23.1. Do not install Payload before upgrading.
- Next.js **16.4.3**; Payload requires **16.4.0+**.
- Payload **3.92.1**, all `@payloadcms/*` packages pinned to the same version.
- TypeScript **6.0.3+**; the current project has 5.9.3.
- Database: SQLite (`file:...`) for development and tests; PostgreSQL for production. **MySQL is not supported.**
- Arabic-first, `lang="ar"`, `dir="rtl"`, logical CSS properties (`ms-*`, `me-*`, `start-*`, `end-*`), Arabic `letter-spacing: 0`.
- Keep the existing visual identity: cream, green, orange, Alexandria/Plex, editorial rules.
- No `[[...]]` tokens and no `href="#"` in rendered pages.
- No sample financial data in production.
- Never commit `.env`, secrets, or database files.
- Every public query uses `overrideAccess: false`. The Local API bypasses access control by default; do not rely on that default.
- Touch targets at least 44px; visible focus; WCAG 2.2 AA.
- One commit per task, after its tests pass.

## Review Focus

- A price saved with a **future effective date** must not appear as today's price. Task 5 tests this.
- A product with **no published price** must show an explicit empty state, not a stale, zero, or previous-season price. Task 8 tests this.
- A site with **missing coordinates** must still appear in the list, and must not break the map for the other sites. Task 10 tests this.
- A public visitor must not read **draft prices, staff users, or private settings** through the API. Tasks 3 and 5 test this.
- Editing in `/admin` must update `/tarifs` and `/` **without a rebuild**, and a failed revalidation must not lose the save. Tasks 5 and 9 test this.
